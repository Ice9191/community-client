# 富新社区服务小程序（UniApp）项目文档
## 一、项目概述
本项目是基于 UniApp 开发的微信端社区服务小程序，面向富新社区居民使用，主要实现业主认证、物业报修、访客预约、社区公告、便民服务、邻里互动等社区综合业务，可快速部署上线。
技术选型：UniApp(Vue3 + Vite) + Pinia + uni-ui，编译目标为微信小程序，后端可采用 Java/PHP/Node 或 uniCloud 云开发。

## 二、整体业务流程
1. 用户进入小程序，发起微信一键授权，获取用户 openid、头像、昵称信息。
2. 系统校验用户信息：
    - 新用户：跳转房屋绑定核验页面，后台比对预录入的业主信息库。核验通过标记为业主，解锁全部功能；核验失败默认为访客身份，仅开放公告等基础浏览功能。
    - 老用户：直接登录，根据业主/访客身份区分页面权限。
3. 用户按需使用报修、访客预约、投票征集等业务，提交对应工单或表单。
4. 物业管理人员在后台接收工单并流转处理，系统通过微信订阅消息推送进度通知。
5. 用户可查看业务处理进度，完成评价等后续操作。

## 六、核心模块说明
### 1. 用户与业主认证模块
实现微信授权登录、房屋信息绑定、业主身份校验，区分业主和访客权限。业主可使用报修、访客预约、投票等全部功能；访客仅可浏览公告、社区基础信息。

### 2. 社区公告模块
后台管理员发布公告，支持置顶、图文内容；小程序首页展示公告列表，用户可查看详情，后台可统计已读数据。

### 3. 物业报修模块
用户选择报修分类，填写问题描述、上传图片，提交报修工单；物业接单、指派维修人员、更新工单状态；消息推送进度，用户完成服务评价。

### 4. 访客预约模块
业主录入访客信息、到访时间，生成临时预约记录；可对接门禁硬件实现通行核验，支持业主自主撤销预约。

### 5. 社区投票/意见征集模块
后台创建投票，支持单选/多选、匿名配置；业主在线参与投票，截止后展示统计结果。

### 6. 便民服务模块
包含家政预约、社区活动报名、快递代收、二手闲置信息发布等便民功能。

### 7. 邻里圈子模块
邻里发布文字、图片动态，邻里之间浏览、互助交流。

### 8. 个人中心模块
展示用户头像昵称、业主房屋信息；集中入口查看我的工单、预约记录、投票记录、消息通知；支持意见反馈、系统设置、退出登录。

## 七、开发与上线流程
1. 需求确认、页面原型设计，输出接口与字段文档
2. HBuilderX搭建UniApp项目，配置pages.json与tabBar
3. 开发公共封装、状态管理、页面开发与接口联调
4. 权限逻辑适配、微信小程序兼容性调试
5. 真机测试，校验表单、消息推送、工单流转等功能
6. 微信公众平台配置小程序AppID、服务器域名、订阅消息模板
7. 代码上传至微信后台，提交审核
8. 审核通过后正式发布，后续迭代维护

## 九、权限说明
- 居民（业主）：全部业务功能权限
- 访客：仅查看公告、基础信息，不可提交报修、预约、投票
- 物业管理员：后台工单处理、公告发布、投票管理、用户信息审核
